# 스토어 설명문 (한국어판 초안 v0.1)

App Store Connect 언어 지역: Korean / 한국어
콘셉트는 일본어판과 동일: "이 키보드 하나로 전부 끝낸다".

**부제목 안 (30자 이내)**
이것 하나로 끝나는 키보드

**설명문**

One Keyboard — 이것 하나로 끝나는 키보드.

일본어, 영어, 숫자. 자주 쓰는 문구, 클립보드 기록, 이모지까지.
문장 하나를 끝내려고 키보드를 오가는 시대는 이제 끝냅시다.

■ 전환 없이, 전부 내장
・일본어 로마지 변환(학습 기능 포함)과 영어 입력을 오가며 자연스럽게
・영어는 자동 수정과 예측 변환 지원. 일본어 모드에서 입력한 영어 단어는 그대로 후보에 표시
・숫자 행이 있는 풀 키보드. 기호도 길게 누르기와 페이지 전환으로 빠르게

■ 패널로 끝나는 입력 지원
・자주 쓰는 문구: 등록해 두고 한 번의 탭으로 삽입
・클립보드 기록: 복사했던 내용을 불러와 바로 붙여넣기
・이모지: 카테고리와 '최근 사용'에서 골라 그 자리에서 삽입
어느 것도 다른 키보드로 전환할 필요가 없습니다.

■ 나에게 맞게 자라는 키보드
・키 배치를 자유롭게 커스터마이즈
・당신이 실제로 쓰는 단어를 학습해, 변환은 쓸수록 똑똑하게

■ 개인정보 보호
일본어 변환은 기기 안에서 처리됩니다. 입력한 내용이 외부로 전송되는 일은 없습니다.
자주 쓰는 문구와 클립보드 기록도 당신의 기기 안에만 저장됩니다.
