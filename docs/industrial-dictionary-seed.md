# 工業・製造業辞書パック 種リスト v0.1

One Keyboard の追加辞書パック（工業・製造業向け）の種リスト。実装前のたたき台であり、収録語は今後、実務での使用頻度に合わせて取捨選択する前提。

## エントリの型

エントリには2つの型がある。

1. **変換型** — かな読みを打つと表記が候補に出る（例: めんとり → 面取り）。一般用語・材質名などが対象。
2. **そのまま型** — 英数字・記号のパターンを打つと、その表記がそのまま候補に出る（例: 6203、M3×0.5、H7）。品番・規格表記が対象で、v0.3.10 の「英字そのまま候補」（日本語入力中に打った英字・数字を変換せず候補に残す機能）と組み合わせて使う想定。

## 収録方針

- メーカーカタログや型番データベースの転載はしない。JIS 規格、一般名詞、一般的な規格表記を中心に収録する。
- 商標名は一般名で収録する（例: ジュラコン → ポリアセタール、テフロン → PTFE として収録し、読み側に商標名は置かない）。
- 会社固有の型番・社内用語はこのパックには入れず、将来のユーザー辞書側で扱う。

## テーブルの見方

| 列 | 意味 |
|---|---|
| 読み・入力 | 変換型はかな読み、そのまま型は入力パターンそのもの |
| 表記 | 候補として出す表記 |
| メモ | 補足。「要確認」は実務検証が要る項目 |

## 検証待ちメモ（実務家レビュー前提）

このリストは v0.1 のたたき台であり、最終収録は実務家（ユーザー本人）の検証を前提とする。

- **表記揺れ**: 「めっき／鍍金」「隙間嵌め／すきま嵌め」「超硬／超硬合金」など、現場で実際に使われる表記に合わせて統一する。
- **読みの重なり**: h7 の読み「えっちなな」は H7 の「えいちなな」と音が近く、変換候補の優先度設計が要る。
- **現場用語の追加・削除**: 実際の業務で打つ語・打たない語に合わせて入れ替える。特に O リング番号、軸受のサフィックス（ZZ、LLU 等）、ローラーチェーンの呼び番号は実使用分だけに絞る。
- **商標の扱い**: 一般名で収録する方針（材質カテゴリ参照）。現場で商標名の方が通りが良い語は、収録可否を個別に判断する。
