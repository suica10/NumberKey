# SNS用語辞書パック 種リスト v0.1

One Keyboard の追加辞書パック（SNS・ネット用語向け）の種リスト。2026-11-13、本人の指摘「SNSの用語が弱い」から新設。SNS は全ユーザーの日常入力なので、**初期状態で有効（標準ON）**とする（工業パックと同格）。

## 収録方針

- 一般辞書で変換しにくい略語・混植表記・新語を中心に収録する（例: りぷ → リプ、てぃっくとっく → TikTok）。
- 通常の辞書で問題なく出る一般語（フォロー、コメント等）は収録しない。
- 誹謗・攻撃目的の語は入れない。荒らし・ステマ等の中立的なラベル語は収録する。
- プラットフォーム名は公式表記（TikTok / YouTube / Threads 等）で収録する。

## 収録しなかったもの

- フォロー / コメント / シェア / アカウント など、一般辞書で問題なく変換できる語。
- 特定個人への攻撃にしか使わないスラング。
- 既に推し活パック側にある語（推し、現場 等）は重複させない。
