# アニメ辞書パック 枠組み＋種リスト v0.1

One Keyboard の追加辞書パック（アニメ向け、販売フェーズ用）の種リスト。今回は「作る仕組み（枠組み）」と「腐らない層の種データ」までを置く。アプリへの組み込みは行わない。

## 目的と位置づけ

- このパックは販売フェーズの商品（全部入り買い切りの一部として同梱）であり、想定読者は海外の日本語学習者・アニメファン層。日本語入力でアニメ用語・作品名・キャラ名を正しい読みで一発変換できることが価値になる。
- 今回の成果物は **枠組み（整備ルール）＋種リスト** のみ。データの大量投入（作品・キャラ層の最新化を含む）とアプリ組み込み（追加辞書チャネル経由の LOUDS 辞書化、設定での辞書ごと ON/OFF、遅延ロード）は **販売直前** に行う前提。
- 種リストは「腐らない層」（一般語彙・定番スラング・長寿作品）中心に全206件。販売時は鮮度ルールに従って話題作層を最新化し、数千件規模まで拡張する想定。

## 枠組み（整備ルール）

### データソース3層

| 層 | 内容 | 備考 |
|---|---|---|
| (a) JMdict 抽出 | JMdict（アニメ・漫画文脈で使われる語、口語・俗語寄りの語）を機械抽出し、人手で選別 | CC BY-SA。帰属表示必須（権利メモ参照） |
| (b) 手作業キュレーション | 作品名・キャラ名・固有名詞。JMdict にはほぼ含まれないため、このパックの核はここ | 公式読みの正確さが命。出典は公式サイト・公式表記 |
| (c) 界隈スラング | SNS・配信・同人界隈で実際に使われる言い回し | 移り変わりが速い。種の段階では定着したものだけを入れる |

JMdict 抽出の選別基準（案）:
- 入れる: アニメ・漫画・ゲーム等の文脈で意味が立つ語、口語・俗語として定着した界隈語、読みに迷いやすい語。
- 外す: 通常辞書で十分変換できる一般語（重複はノイズになる）、読みが複数に割れて代表読みを決められない語、一過性の流行語。

### 読み付けルール

- **公式読み優先**。作品名・キャラ名は公式サイト／原作の表記とふりがなを正とする。
- **キャラ名は難読でも正確なふりがな必須**。確信が持てない読みは推測で書かず、収録しないか、メモ欄に「要確認」を付ける（この辞書は読みの正確さが価値そのもの）。
- 英字タイトルはカタカナ読みで登録する（例: わんぴーす → ONE PIECE）。略称（ワンピ、エヴァ等）も変換型の別行として登録し、メモに「略称入力」と明記する。
- 「・」「☆」「×」等の記号は表記列の正式表記に保持し、読みからは除く（例: もんきーでぃーるふぃ → モンキー・D・ルフィ）。
- 長音・促音・拗音は公式表記に合わせる。
- 複合語（聖地巡礼、伏線回収のような言い回し）は、分解せず語として登録する。

### 鮮度ルール

- 作品・キャラはクールごとに入れ替わる。**腐りやすい層（直近数年の話題作・キャラ）は販売直前に最新データで投入**し、以後も更新対象とする。種リストには原則として入れない（例外的に入れたものには「販売時に要再確認」とメモする）。
- 腐らない層（一般語彙・定番スラング・長寿作品・国民的キャラ）は種として今置いてよい。
- 放送終了＝即削除ではない。長期に参照され続ける作品（再放送・配信・続編で生き続けるもの）は残す。

### 変換時の扱い

- パックの候補は **通常辞書より低優先** にする（既定の設計）。日常会話の変換にアニメ語が割り込むノイズを防ぐ。
- 設定で **辞書ごとに ON/OFF** できる。**OFF の辞書はロード自体しない**（メモリ・候補検索のコストゼロ）。全部入りで同梱しても、使わない人にコストを払わせない。
- 初期状態（デフォルト ON/OFF）は販売時に最終判断する。

### 権利メモ

- JMdict は EDRDG のライセンス（CC BY-SA 相当）。販売時はアプリ内に帰属表示（クレジット）を必ず入れる。
- 作品名・キャラ名は、変換辞書の **見出し語としての収録**（事実の参照）にとどめる。作品の画像・ロゴ・本文等の著作物は含めない。
- 商標・作品名の表記は正式名称をそのまま表記列に使う。

## エントリの型とテーブルの見方

エントリには2つの型がある。

1. **変換型** — かな読みを打つと表記が候補に出る（例: とうとい → 尊い）。種リストの主体。略称からの変換（例: わんぴ → ONE PIECE）も変換型の行として収録し、メモに「略称入力」と記す。
2. **そのまま型** — 英字略称などを打つと、その表記がそのまま候補に出る（例: OVA → OVA）。第6節にまとめる。

| 列 | 意味 |
|---|---|
| 読み・入力 | 変換型はかな読み、そのまま型は入力パターンそのもの |
| 表記 | 候補として出す表記 |
| メモ | 補足。「要確認」は販売前に検証が要る項目、「販売時に要再確認」は鮮度ルールによる鮮度チェック対象 |

## 収録しなかったもの・今後の拡張

- **声優名**: 人数が膨大で読み確認のコストが高く、入れ替わりも速いため種には入れない。販売時に需要を見て別途キュレーションを検討する。
- **直近の話題作・一過性の流行語**: 鮮度ルールにより種では意図的に外した。販売直前に最新化して投入する。
- **各作品のサブキャラ・敵役**: 読みの確信が持てる範囲が狭いため種では主要キャラのみ。販売時に作品ごとの公式資料で確認しながら拡張する。
- **ゲーム・アニメ以外の界隈語**（VTuber 等）: このパックの範囲外。必要なら別パックで扱う。

## 検証待ちメモ

- 「要確認」3件（黒歴史の読み、ざまあ の表記ゆれ、やおい の位置づけ）は販売前のデータ整備時に解消する。
- 「販売時に要再確認」5件（比較的新しい定番作品）は、鮮度ルールに従い販売直前に定番として定着しているか再判定する。
