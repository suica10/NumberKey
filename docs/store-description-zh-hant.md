# 商店說明文（繁體中文版草稿 v0.1）

App Store Connect 語言區域：Chinese (Traditional) / 中文（繁體）
概念與日文版一致：「這一塊鍵盤，全部搞定」。

**副標題方案（30 字以內）**
一塊鍵盤，全部搞定

**說明文**

One Keyboard —— 一塊鍵盤，全部搞定。

日語、英語、數字。常用短語、剪貼簿歷史、表情符號。
不必再為了打完一句話，來回切換鍵盤了。

■ 無需切換，全部內建
・日語羅馬字轉換（附學習功能）與英語輸入，在同一塊鍵盤裡自然切換
・英語支援自動修正和預測輸入。在日語模式下輸入的英文單詞，會原樣出現在候選詞中
・附數字列的完整鍵盤，長按與翻頁即可快速輸入符號

■ 面板裡完成一切輔助輸入
・常用短語：登記常用句子，一鍵插入
・剪貼簿歷史：叫出複製過的內容，隨時貼上
・表情符號：依分類或「最近使用」瀏覽，就地插入
以上全部無需切換到其他鍵盤。

■ 越用越合手
・按鍵配置可自由自訂
・轉換會學習你真正使用的詞彙，越用越聰明

■ 隱私
日語轉換全部在裝置本地處理。你輸入的內容不會傳送到任何地方。
常用短語和剪貼簿歷史也只保存在你的裝置中。
