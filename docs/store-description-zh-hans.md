**说明文**

One Keyboard —— 一块键盘，全部搞定。

日语、英语、数字。常用短语、剪贴板历史、表情符号。
不必再为了打完一句话，来回切换键盘了。

■ 无需切换，全部内置
・日语罗马字转换（带学习功能）与英语输入，在同一块键盘里自然切换
・英语支持自动修正和预测输入。在日语模式下输入的英文单词，会原样出现在候选词中
・带数字行的完整键盘，长按与翻页即可快速输入符号

■ 面板里完成一切辅助输入
・常用短语：登记常用句子，一键插入
・剪贴板历史：调出复制过的内容，随时粘贴
・表情符号：按分类或「最近使用」浏览，就地插入
以上全部无需切换到其他键盘。

■ 越用越合手
・按键布局可自由定制
・转换会学习你真正使用的词汇，越用越聪明

■ 隐私
日语转换全部在设备本地处理。你输入的内容不会发送到任何地方。
常用短语和剪贴板历史也只保存在你的设备中。
